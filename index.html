Featured Case Study

Clinic Management System

🚨 The Problem

Clinics struggled with manual paper records, lost patient histories, and overlapping appointment scheduling.

💡 The Solution

Built a real-time cloud-based booking system with role-based access (doctor, reception, patient) using Firebase/Firestore and Cloudinary for media.

⚙️ Key Features

Real-time listeners (onSnapshot) instead of polling across reception/booking/admin pages, secure media handling via Cloudinary, and granular role permissions.

📈 Result

Eliminated manual paper-based scheduling, achieved zero booking conflicts, and enabled instant real-time synchronization across all staff dashboards.
